# 初中免费试卷下载器（Windows）

## 功能
- 面向七、八、九年级；支持语文、数学、英语、物理、化学、生物、历史、地理、道德与法治。
- 使用公开搜索结果检索试卷页面。
- 仅保留标题或摘要中明确出现 `2025-01-01` 至今日期证据的结果。搜索引擎索引时间不会被当成发布日期。
- 尝试从公开页面提取 PDF、DOC、DOCX 下载链接，并支持选中下载或批量下载。
- 按“年级\学科”保存文件；为每份下载文件生成 JSON 来源记录和 SHA-256。
- 检查 PDF 文件头/EOF、DOCX 压缩包结构、DOC 文件头。结构校验不能代替人工逐页核对。

## Windows 使用
1. 安装 Python 3.10 或更高版本，并勾选 Add Python to PATH。
2. 解压项目文件夹。
3. 双击 `install_requirements.bat` 安装依赖。
4. 双击 `app.py` 启动，或在命令行运行 `python app.py`。
5. 选择年级、学科、关键词，点击“搜索试卷”；选择结果后点“下载选中”或“批量下载全部”。
6. 下载默认保存到“文档\初中免费试卷\年级\学科”。

## 生成独立 EXE
在 Windows 电脑上双击 `build_windows.bat`。完成后 EXE 位于 `dist\初中免费试卷下载器.exe`。此项目包是在非 Windows 环境制作的，EXE 需要在 Windows 上生成并实际运行验证。

## 重要限制
- 当前版本通过 Bing RSS 搜索公开网页，搜索结果数量和可用性受搜索引擎影响；并不保证覆盖所有教育网站。
- 学科网等网站若资源需要会员、登录、验证码或付费，本软件不会绕过限制。只会下载无需绕过访问控制即可公开取得的文件。
- 搜索结果中的日期必须明确出现在标题/摘要中，无法确认发布日期的资源会被保守过滤，因此可能漏掉真实的近期试卷。
- 网页能打开不代表允许下载；请遵守来源网站的使用条款和版权要求。
- “结构校验通过”只表示文件容器格式基本正常，不代表内容一定是完整试卷。下载后请打开文件检查页数、答案页和题目内容。

## 故障排查
- 搜索失败：检查网络能否访问 Bing；部分网络环境可能屏蔽 RSS 搜索。
- 无公开文件链接：该页面可能只有预览、需要登录/付费，或下载按钮使用了动态脚本；软件不会尝试绕过。
- 文件校验失败：已删除未通过校验的文件，避免将错误网页保存成试卷。

## 不在本机安装 Python，在线生成 Windows EXE

项目包含 `.github/workflows/build-windows.yml`。将整个项目上传到自己的 GitHub 仓库后：
1. 打开仓库的 **Actions** 页面。
2. 选择 **Build Windows EXE**。
3. 点击 **Run workflow**（或向 main/master 分支推送提交）。
4. 等待任务完成，在该次运行页面底部的 **Artifacts** 下载 `初中免费试卷下载器-Windows-x64`。
5. 解压后即可取得 `初中免费试卷下载器.exe`。

此方式由 GitHub 的 Windows 运行环境编译，当前交付环境本身不是 Windows，因此这里不声称已经生成或测试了 EXE。
